# Daily recap runbook (scheduled task, ~8:23 AM ET)

Goal: post last night's Heat Check results as an Instagram Reel AND as a TikTok (fully automatic, no human step).
Work without asking questions. Never name sportsbooks. Post only to Instagram account id 17841480704510652 (courtside.edge.app).

1. Get the data. Read `data/record.json` from the Courtside Edge artifact (https://claude.ai/artifact/BjcjLESc4j84Qu8nPBQGZp) with the Artifact tool's read action (load the tool with ToolSearch `select:Artifact` if deferred), saving to a file with out_dir.
2. Get the repo. Call add_repo (access push) for courtsideedgeapp-tech/courtside-media, then `git clone --depth 1` into the workspace path it returns.
3. Decide the date. YESTERDAY = `TZ=America/Toronto date -d yesterday +%F`. The latest graded day in record.json must equal YESTERDAY. If not, wait 20 minutes and re-read once. If still not graded, stop and report "grading not ready" (do not post an older day).
4. Skip if done. If YESTERDAY is in ledger.json `instagram.recap`, stop with "already posted".
5. Render. `pip install pillow --break-system-packages` if PIL is missing; ffmpeg must exist. Run
   `python3 -I studio/recap.py RECORD_JSON posts/YESTERDAY YESTERDAY`. It writes recap_DATE.mp4, recap_DATE.txt (caption), recap_DATE.json (facts), and two PNG frames, and recap_DATE_cover.jpg (the Instagram cover; frame 0 is near-black, so ALWAYS pass it).
6. Check. Read recap_DATE.json: hits/misses must match the record entry, and look at recap_DATE_results.png. Fix and rerun if anything is wrong.
7. Publish files. Add posts/DATE/*, commit, `git push origin HEAD:main`. Verify `curl -sI https://raw.githubusercontent.com/courtsideedgeapp-tech/courtside-media/main/posts/DATE/recap_DATE.mp4` returns 200 (retry for ~2 minutes).
8. Post to Instagram with the Windsor.ai for Social Media connector (ToolSearch "windsor"): execute_action, connector "instagram", action "create_video_post", account "17841480704510652", params video_url = the raw URL, caption = the contents of recap_DATE.txt exactly, share_to_feed true, cover_url = raw URL of recap_DATE_cover.jpg (same folder; verify it returns 200 too). Never post a Reel without cover_url.
9. Post to TikTok with the ScheduleNChill connector (ToolSearch "schedulenchill"). Skip if DATE is in ledger.json `tiktok.recap`. Call get_accounts (use the tiktok account, currently id 372, @courtside.edge.app), get_tiktok_creator_info (must show can_post true), upload_media with source "url" = the raw mp4 URL (filename recap_DATE.mp4, alt_text a one-line description, folder "recaps"), then schedule_post with when "now", account_ids [id], media_ids [media_id], content = the contents of recap_DATE.txt exactly, platform_options [{account_id, options:{privacy_level:"PUBLIC_TO_EVERYONE", allow_comment:true, allow_duet:false, allow_stitch:false}}]. Wait ~60 s, then get_post must show status published; retry_post once if it failed. Do not add a TikTok sound; the video already has its own beat.
10. YouTube Short via ScheduleNChill (same connector; skip if DATE is in ledger.json `youtube.recap`). Account: the youtube one from get_accounts (currently id 373, @courtsideedge). Reuse the media_id from step 9 (no second upload). schedule_post when "now", account_ids [id], media_ids [media_id], content = recap_DATE.txt contents + a final line `#Shorts`, platform_options [{account_id, options:{title: first line of the caption (max 100 chars), tags:["NBA","NBAStats","HeatCheck","CourtsideEdge","Shorts"], privacy:"public", category:"27", made_for_kids:"no", altered_content:"no"}}]. After ~60 s get_post must show published; retry_post once if failed. A YouTube failure must not undo Instagram or TikTok.
11a. Collect invite requests (the signup method is comments). Pull recent comments with Windsor get_data: connector "instagram" fields [comment_id, comment_username, comment_text, comment_timestamp, media_permalink] and connector "tiktok_organic" fields [comment_id, comment_username, comment_text, comment_video_id, date], date_preset last_7d (if a connector errors, skip it and say so). Keep comments whose text contains "invite" (case-insensitive). Append each NEW one to `invites.json` in the repo as {"platform","username","comment_id","text","seen":"DATE"}, deduped by comment_id (create the file as {"requests":[]} if missing). Never reply to or message anyone. Report the new count and the running total.
11. Update ledger.json: append DATE to `instagram.recap`; `tiktok.recap` and `youtube.recap` (create keys if missing) with the ScheduleNChill post ids. Commit and push.
12. Finish with ONE short message for the owner: the hook variant used (recap.py rotates 3 daily: star name, number, invite-only), the new invite requests (count, total, usernames), the record (e.g. "3-0, season 46-23"), Instagram media id, TikTok and YouTube post ids and status. If anything failed, say exactly what (a failed TikTok step must not block or undo the Instagram post).
